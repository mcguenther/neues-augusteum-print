# Steckbare Gebäude (1:1300)

Sechs Hohlgebäude zur Steckplatte `../steckplatte_1zu1300.stl`, erzeugt mit `python3 -m plug.buildings`. Je Gebäude die STL und eine JSON
mit den Prüfwerten (Volumen, Kassette, Rohrstütze, Brücken, Kragstücke, Kollision). Schnittbilder: `vorschau/steckmodul_campus/gebaeude/`.

**Slicer-Einstellungen: [`plug/slicer.md`](../../../plug/slicer.md)**. Kurz: Boden aufs Bett, Support aus, 0,2 mm Schicht, 2 Wandlinien,
4 obere und 2 untere Deckschichten, Gyroid 10 %, „Ensure vertical shell thickness“ aus, Hochhaus mit Rand. Ungedruckt.
